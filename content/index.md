# ARCH: Stack Overflow — design vault

The team's design documentation. A 3D platformer set inside a 2000s corporate operating system, made by Grupo 1 at the Instituto Politécnico de Bragança — Design de Jogos Digitais, Polo de Mirandela.

You are reading a published subset of the working vault. Production notes, meeting records and anything with personal data stay private.

## If you are new to the project

Read these three, in this order:

1. **[[Premise & Synopsis]]** — what the game is about
2. **[[Game Structure]]** — how the game is shaped: the hub, the levels, how you move between them
3. **[[Glossary]]** — the vocabulary. Most confusion on this project has been two people using one word differently

Then **[[Pillars & MDA]]** for why the game is the way it is, and **[[Art Direction - Frutiger Aero]]** for how it looks.
