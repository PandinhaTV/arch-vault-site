# Time Medals

Bronze, silver and gold, awarded on completion time. Decided 2026-08-09. Thresholds not yet researched.

## Why it matters more than it looks

It closes a gap that had been open since the level design was written. [[Aquatic]] has two routes — the normal one that presses every button, and an expert one that skips all of them to preserve flow. Until now the expert route's only reward was that it felt better. See [[Decision - Buttons can be skipped to preserve flow]].

Medals make the expert route legible. A player who never notices the skips now has a number telling them a faster run exists, which is what turns a hidden route into a thing people hunt for.

It also serves the Achiever half of the stated audience, who currently have only file collection to chase. → [[Pillars & MDA]]

## What needs deciding

**Where the thresholds come from.** The usual approach is to set gold at roughly a good developer run, silver at a competent first-clear, bronze at completion. That requires someone to actually run the level repeatedly, which nobody has done yet.

**Whether medals gate anything.** If they only display, they are a personal best. If they unlock skins, they become the reason to replay — and [[Skins]] currently has no unlock method beyond "a shop".

**Whether the timer is visible during play.** A visible timer changes how the level feels moment to moment, and this game is themed on flow. A timer shown only at the end preserves the mood; one shown during play creates pressure. These are different games.

**How it interacts with exploration.** The world is the main attraction and players are meant to wander. A timed level sits oddly next to that unless the timer only runs inside levels.
